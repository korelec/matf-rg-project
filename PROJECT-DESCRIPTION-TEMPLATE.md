# NIGHT IN THE WOODS

#### 118/2023 - Tea Korelec  

A cottage with fire pit and some logs surounded with circle of trees. Fire is a gradient that has small animation changing colors and gui to control the light.
One directional light (moon) and one point light (fire).
Implementation of parallax mapping on the ground, best seen looking from above.
## Controls

W -> forward  
A ->left  
S -> backward  
D -> right  
Q -> up  
E -> down  
F -> on/off gui for light
scroll -> zoom
